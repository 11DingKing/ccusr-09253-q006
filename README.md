# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 场地容量联动

集中实训活动受场地容量上限约束。系统对场地、容量版本和活动排期版本做独立配置，事件重放时将已确认签到与排期场次求交，按场地扫描同时段占用：

- 超过承载量的**超额区间**会被标记（`overruns`/`excess_segments`），区间内未获得座位的签到记为 `held`，对应学时**暂缓**（不计入 confirmed/total），等待管理员核对实际名单；
- 管理员通过**名单确认**（追加式 `roster_confirm` 事件）给出实际名单：`released` 按给定顺序优先入座释放学时，`excluded` 的签到不占容量、学时排除；同一名单的多次确认为增量裁决，最新一次提及优先，全程确定性重放；
- 排期更正通过发布**新的排期版本**完成，默认只按受影响活动（含同场地同时段共用容量的活动）重算；已冻结快照固化生成时的容量/排期版本，事后更正不会改变历史快照；
- 容量与排期版本均为**只追加、不可变**，同版本号内容冲突返回 409。

相关接口（均位于 `/api/plans/{plan_version}` 下）：

| 能力 | 接口 |
| --- | --- |
| 场地登记 | `POST /venues` |
| 容量版本配置 | `PUT /venues/{venue_id}/capacity-versions` |
| 排期版本配置（含更正） | `PUT /schedule-versions` |
| 冲突/超额预览（可钉住版本对比） | `POST /capacity/preview` |
| 实际名单确认（部分确认） | `POST /schedules/{schedule_id}/roster-confirmations` |
| 更正影响查询（受影响活动/学生/签到） | `POST /capacity/impact` |

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

python3 -m pytest -q

python3 -m compileall -q app tests
